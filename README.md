# 🐱 Stage Zero Backend Task — Profile Endpoint

This project implements a simple backend API that returns developer profile information and a random cat fact using the [Cat Facts API](https://catfact.ninja/fact).

---

## 🚀 Features
- `/me` endpoint returning structured JSON data
- Dynamic UTC timestamp
- Live integration with Cat Facts API
- Rate limiting (prevent spam)
- Logging (Winston + Morgan)
- Error handling for failed API calls
- CORS enabled

---

## 🧠 Tech Stack
- **Node.js**
- **Express**
- **Axios**
- **Morgan**
- **Winston**
- **Express-rate-limit**
